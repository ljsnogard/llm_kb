# dev-notes

这个文件夹是用来存放开发过程中遇到的技术困难，以及记录技术决策的前因后果。

## 文件内容及规范

文件格式一律为 markdown 格式。

### 文件名规范

`[模块名]-[日期]`。其中日期时间格式为 `YYYYMMDD-hhmm`

跨模块、项目级的记录用 `llm_kb-<日期>`（例如
[`llm_kb-20260917-1655.md`](llm_kb-20260917-1655.md)：仍在生效的决策与开放事项）。

### 仓库根目录的 `dev-notes.md` 已经删除

那份文件里的进度表、剩余工作与大部分小节都属于已废弃的 salvo 路线；
其中**仍然生效**的内容已归纳进本目录（见上面那份 `llm_kb-*`）。

旧文件里各小节被引用的地方（例如代码注释里的"`dev-notes.md` §2.5"）已经改指向
本目录；`kb_svc_salvo` 里的引用保持原样——那个 crate 整体在废弃之列，
它的模块文档只作为历史资料保留。

新记录请一律写进本目录。
